# 🙋🏼‍♂️ Hi! I'm Ale!

I've always loved technology, ever since I was a kid crawling torrent websites for games and building my first PC. That led me (thankfully, I guess?) to study Software Engineering (Ingeniería Informática in Spain, kind of Computer Science + Software Engineering) and, later, a Master's Degree in Artificial Intelligence.

After some years of DevOps + Backend + Swiss Army knife, I moved to a very AI-driven environment, which I love. These days I build AI tooling for developers and agents.

📍 Zaragoza, Spain 🇪🇸

## 🔭 What I'm up to

- Constantly testing models, agent harnesses and skill designs to figure out what actually works
